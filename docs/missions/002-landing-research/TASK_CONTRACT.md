## MISSION

Research how to build a beautiful, modern landing page for AtoEnglish —
a Vietnamese-first English-learning product. `/` is currently a blank
placeholder after the notebook-style landing was rejected and deleted.

## PROBLEM

The site has no landing. A previous redesign was rejected by the owner
("chẳng hiểu mày thiết kế cái gì luôn"). Before designing again we need
evidence: what do the best language-learning landing pages do, what is
modern in 2025–2026, and what can this codebase actually support.

## SCOPE

- Parallel research streams: (a) modern edtech landing design trends,
  (b) competitor teardown (ELSA, Duolingo, Cake, Babbel, VN market),
  (c) repo capability audit (design system, fonts, motion, constraints,
  salvageable copy from deleted landing `71c2286f^`).
- Output: one synthesized research report + design direction proposal.

## NON-GOALS

- No implementation. No UI code changes this mission.
- No revival of the rejected notebook design.
- No new product direction — copy must stay honest (28-day / 10–15 min
  pilot promise is the authorized positioning; no unsupported claims).

## ACCEPTANCE CRITERIA

1. Report separates fact / observation / inference / recommendation.
2. Concrete competitor evidence with named pages + what to borrow/avoid.
3. Repo-constrained direction (what stack/fonts/motion we have).
4. A recommended design direction the owner can approve or reject.

## OUTPUT

`docs/missions/002-landing-research/RESEARCH.md` + ledger entry.
